# saldo.

Dashboard pessoal e controle financeiro. Projeto Next.js + TypeScript.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

Importe o repositório **vidaaal/saldo** na Vercel e selecione Next.js. Sem variáveis de ambiente para o protótipo.

## Importante

Esta primeira versão é um protótipo: lançamentos são guardados **apenas no navegador**, sem login, banco de dados ou IA. Use Exportar CSV para guardar cópias. As faturas são projeções estáticas e não são recalculadas automaticamente. Não use para guardar dados financeiros sensíveis.
